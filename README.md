# CREME — Food Culture Research Bank

Vercel-ready Next.js package for the CREME visual and listening libraries.

## Upload to Vercel

1. Create a new project in Vercel.
2. Upload this folder or publish it through a GitHub repository.
3. Keep **Framework Preset** set to **Next.js**.
4. Keep the standard install command (`npm install`) and build command (`npm run build`).
5. No environment variables are required for the current version.

## Local preview

```bash
npm install
npm run dev
```

The package includes the home page, the podcasts page, the podcast feed endpoint, and all local images and videos.
